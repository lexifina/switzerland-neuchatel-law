# Art. 46
1 La personne qui établit son domicile dans une commune reçoit une attestation de domicile, valable au jour où elle est délivrée; une seule attestation, mentionnant les personnes qui font ménage commun, peut être établie pour les familles ou les partenaires enregistrés.
2 La personne qui déclare un séjour dans une commune reçoit une attestation de séjour qui est délivrée pour la durée d’une année; elle peut être renouvelée.
