# Art. 18 Financement
1 Le fonds peut, sur demande, participer au financement des centres d'apprentissage dans le canton pour les contrats d’apprentissage neuchâtelois.
2 Le subventionnement est octroyé dans le respect des limites fixées à l’article 3, lettre d, LFAPP.
3 La période considérée est l’année scolaire.
