# Art. 23 Périmètres archéologiques
1 L'État détermine, sur la base de la carte archéologique, les périmètres archéologiques, à savoir les secteurs dans lesquels des vestiges archéologiques sont attestés ou soupçonnés.
2 Dans ces périmètres, tous les travaux dans le sol ou sous les eaux doivent faire l'objet d'une autorisation.
3 Les périmètres archéologiques figurent sur les plans communaux d’affectation des zones.
