# Art. 146 Dispositions d’exécution
Le Conseil d’Etat arrête pour le surplus les dispositions d’exécution nécessaires pour le présent chapitre en se fondant notamment sur l’ordonnance du DFF sur l’imposition à la source dans le cadre de l’impôt fédéral direct (Ordonnance sur l’imposition à la source, OIS), du 11 avril 2018.
