# Art. 5 Produits interdits
Les produits plastiques à usage unique dont l’usage est interdit sont les suivants :
a) couverts (fourchettes, couteaux, cuillères, baguettes) ;
b) assiettes et bols ;
c) pailles ;
d) bâtonnets mélangeurs pour boissons ;
e) récipients pour aliments ;
f) gobelets, verres, tasses et autres récipients pour boissons, y compris leurs moyens de fermeture et couvercles.
