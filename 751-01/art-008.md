# Art. 8 Principe
1 Un modèle de géodonnées est au moins associé aux géodonnées de base de droit cantonal ou communal.
2 Le modèle de géodonnées de base doit être en trois dimensions si nécessaire.
3 Le modèle de géodonnées doit être conçu pour permettre l’historisation si celle-ci est nécessaire. L’article 19 ci-dessous est réservé.
