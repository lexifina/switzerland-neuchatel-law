# Art. 22 Récusation
1 Les motifs de récusation sont ceux prévus par le code de procédure civile (CPC), du 19 décembre 2008.
2 Le président statue sur les récusations des membres. S'il est lui-même récusé, les dispositions du code de procédure civile sur la récusation des juges sont applicables. Il est remplacé par le vice-président.
