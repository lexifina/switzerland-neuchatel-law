# Art. 20 Locataires
1 Dans le cas où la mesure d'encouragement consiste dans la prise en charge d'intérêts, les logements ne peuvent être loués qu'à des personnes de condition modeste, selon les normes édictées par le Conseil d'Etat. Une occupation raisonnable de ces logements doit être assurée.
2 Lorsque les revenus d'un locataire dépassent les normes applicables, l'aide des pouvoirs publics est réduite en proportion.
