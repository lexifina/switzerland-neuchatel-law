# Art. 23 Risques éléments naturels couverts
Les bâtiments sont assurés contre les dommages causés par :
a) l'ouragan ;
b) la grêle ;
c) les crues et les inondations ;
d) les avalanches ;
e) le poids et le glissement de la neige sur les toits ;
f) les glissements de terrains ;
g) les chutes de pierre et les éboulements de rocher ;
h) les dolines.
